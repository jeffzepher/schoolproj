# 星册 · 班级积分

为老师设计的静态积分管理工具，直接兼容 GitHub Pages，无需服务器和账号。

## 使用

1. 在「学生管理」添加学生，或下载 Excel 模板并导入名单（首行：学号、姓名）。支持 xlsx、xls、csv，保留文本学号的前导零；同学号更新姓名，保留积分。导入前提供预览，遇到无效行会整批提示。
2. 在「积分项管理」设置项目名称、报表简称、默认正负分值。修改或删除项目不会改变已有记录。
3. 在「日常记分」选择一位或多位学生、日期、积分项，确认记分；可调整本次分值并加备注。错误记录在最近记录中撤销。
4. 在「统计报表」选择日报、周报（周一到周日）、月报，调整日期与排序。报表总分仅统计选定期间；不含周末时，总分与明细同时排除周末。
5. 导出 PNG 为本机绘制的高清表格；超长表格自动分为多张。导出 PDF 会打开系统打印窗口，选择「另存为 PDF」。电脑建议横向 A4，手机按系统支持选择保存或分享 PDF。月报以「每日扣分明细」一列汇总，避免 31 列过窄。

## 手机桌面与离线

本站采用相对路径的 PWA 清单、192/512 PNG 图标、Apple 图标和 Service Worker，适用于 GitHub Pages 的 `/schoolproj/` 子路径。

- iPhone/iPad：Safari 打开，分享 → 添加到主屏幕。
- Android：Chrome/Edge 打开，页面「添加到桌面」或浏览器菜单 → 安装应用。
- 首次完整联网打开并完成缓存后，可离线管理、Excel 导入和 PNG 导出。PDF 依赖系统打印功能。实际安装按钮与打印行为因浏览器而异。
- 未来修改静态文件后应同步更新 `sw.js` 中的缓存版本号，关闭所有旧页面再重新打开以激活新版本。

## 数据

数据使用 `localStorage` 保存在当前设备、当前浏览器、当前网站来源下，不上传云端，也不自动跨设备同步。桌面应用在部分系统可能使用独立数据空间。务必定期通过「数据备份与恢复」导出 JSON；换设备时导入恢复。恢复前会确认替换，清理浏览器数据可能导致丢失。删除学生会同时删除其记录，有明确确认提示。

初次空班级可在「数据备份与恢复」载入示例班级。示例姓名均为虚构。

## 本地运行与检查

需要 Node.js 18+，无需安装依赖。

```sh
npm start
npm test
```

打开 http://127.0.0.1:4173 。GitHub Pages 使用仓库根目录直接部署，无构建步骤。运行入口是 `index.html`，无需上传测试或本地服务器文件。

## 第三方组件

`vendor/xlsx.full.min.js`：SheetJS Community Edition 0.20.3（Apache-2.0），用于在本机导入 Excel 和生成模板。许可证见 `vendor/xlsx-LICENSE.txt`。无外部字体、统计脚本或运行时 CDN 依赖。
